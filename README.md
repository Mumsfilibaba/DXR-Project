## DXR Project

A hobby rendering and game engine for experimenting with graphics APIs, engine architecture, and modern rendering techniques. The project started as a DirectX Raytracing (DXR) testbed and has grown into a multi-backend platform with a shared RHI, a render graph, and a small editor-capable sandbox.

Supports **Windows** (D3D12 and Vulkan) and **macOS** (Vulkan through MoltenVK). The codebase is organized into runtime modules with project files generated by Premake. See [CodeStandard.md](CodeStandard.md) for coding conventions.

---

### Features

#### Graphics and platform

- **RHI backends:**
  - D3D12
  - Vulkan
  - Null (headless tests)
- **Cross-platform:**
  - Windows and macOS
  - Modular or monolithic linking on each
- **Bindless support** on supported backends
- **Render graph:**
  - Transient resources
  - Barrier planning
  - Pass culling
- **Shader pipeline:**
  - HLSL via DXC
  - Shader caching
  - Permutation system

#### Rendering

- **Deferred path:**
  - Depth prepass
  - G-buffer base pass
  - Tiled light culling
- **Forward rendering**
- **Skybox**
- **Materials:**
  - Normal mapping
  - Parallax occlusion mapping
  - PBR with image-based lighting
- **Shadows:**
  - Cascaded shadow maps
  - Point-light shadow atlases
- **Ray tracing:** (D3D12 / Vulkan where supported)
  - Ray-traced reflections
  - Denoising
  - Debug visualizations
- **Post-processing:**
  - Screen-space ambient occlusion
  - Temporal anti-aliasing
  - FXAA
  - Tonemapping

#### Engine and editor

- **Editor:**
  - Selection outline
- **Debug tooling:**
  - Texture debugger
  - In-engine console
  - Frame profiler (ImGui)
- **Custom core types:**
  - Containers
  - Strings
  - Math
  - Memory
  - Threading
  - Platform abstractions
- **Automated tests and benchmarks:**
  - Core
  - RHI
  - RendererCore

#### Planned

- Metal
- Screen-space reflections (SSR)
- Spotlights
- Local environment probes
